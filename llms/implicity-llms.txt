# Implicity

> Implicity is a Paris-based digital health company operating a vendor-neutral, cloud-based cardiac remote
> monitoring platform. Its software ingests and normalizes transmissions from cardiac implantable
> electronic devices (CIED) and implantable loop recorders across every major manufacturer, then applies
> AI-based triage to surface clinically actionable alerts for care teams.

This file was GENERATED by API Evangelist from the public Implicity surface on 2026-08-17. Implicity does
not publish an llms.txt of its own (404 on implicity.com, www.implicity.com and patients-info.implicity.com;
app.implicity.com answers 200 with a JavaScript SPA shell for every path, which is not a document).

## What an agent can and cannot do here

Implicity markets a "comprehensive API and integration framework for seamless data exchange with core
hospital systems" and bidirectional EHR/EMR integration on its IT-teams page. **No public API reference,
developer portal, or machine-readable contract is published.** The API host `api.implicity.com` resolves
(AWS eu-west-3) and answers HTTP, but returns a bare `text/plain` "Not Found" body on all 21 paths probed,
including `/openapi.json`, `/swagger.json`, `/v3/api-docs`, `/graphql`, `/metadata`, `/fhir/metadata` and
`/.well-known/smart-configuration`. There is no MCP server (`mcp.implicity.com` does not resolve), no A2A
agent card, no AsyncAPI, no webhook catalog, and no public Postman workspace. An agent cannot call
Implicity today; integration is arranged through the company's sales and IT teams.

## Products

- [CIED Remote Monitoring](https://implicity.com/cied-remote-monitoring/): Vendor-neutral cloud platform aggregating data from cardiac implantable electronic devices across manufacturers.
- [Heart Failure Remote Monitoring](https://implicity.com/hf-remote-monitoring/): Real-time CIED data collection for heart-failure patient management.
- [SignalHF Predictive AI](https://implicity.com/signalhf-predictive-ai/): AI predictive analytics for heart-failure remote monitoring.
- [ILR ECG Analyzer](https://implicity.com/ilr-ecg-analyzer/): Analysis tooling for implantable loop recorder ECG data.
- [AF Alert Management](https://implicity.com/af-alert-management/): Atrial fibrillation alert management and triage.
- [InLink](https://implicity.com/inlink/): In-clinic capture of device PDF and raw data, transmitted automatically to the platform or to an EMR.
- [Patient Connectivity Management](https://implicity.com/patient-connectivity-management/): Monitoring and remediation of patient device connectivity and transmission gaps.
- [Advanced Research Tool](https://implicity.com/advanced-research-tool/): Device-data collection and exploration for clinical studies.
